# scripts

Helper scripts that produce pipeline inputs and figures.

| Script | Produces |
|---|---|
| `export_polygons.py` | CVAT annotation polygons as JSON |
| `export_tiles.py` | annotated tiles and their manifest |
| `registration_contact_sheet.py` | outline overlay of every registered pair |
| `manuscript_figure.py` | the necrosis figure of the SPT manuscript |
| `hepatobench_figures.py` | HepatoBench curves, confusion matrix, paper comparison, patch grid |
| `cyp2e1_readout.py` | CYP2E1-positive area per slide, split by necrosis, with maps and a contact sheet |
